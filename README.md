# Система электронного обучения

Кроссплатформенное настольное приложение для создания, редактирования и прохождения онлайн-курсов с тестами.  
Реализовано на **C#** + **Avalonia UI** с использованием паттерна **MVVM**.

Приложение позволяет:
- Создавать и редактировать учебные курсы
- Загружать материалы (текст, файлы)
- Проходить курсы в режиме чтения
- Проходить тесты для проверки знаний

## Основные возможности

- Создание и редактирование курсов (название, описание, модули, материалы)
- Загрузка и хранение файлов материалов через **S3-совместимое хранилище** (Timeweb Cloud)
- Просмотр учебных материалов в удобном интерфейсе
- Система тестирования (вопросы, варианты ответов, оценка результатов)
- Подключение к удалённой базе данных **MySQL** через Timeweb Cloud
- Полностью асинхронная работа с данными (MVVM + сервисы)

## Технологический стек

- **Язык**: C# (.NET SDK 9.0)
- **UI-фреймворк**: [Avalonia UI](https://avaloniaui.net/) 11.3.9 — кроссплатформенный, аналог WPF
- **Архитектура**: MVVM
- **База данных**: MySQL 8.4.4 (удалённый сервер Timeweb Cloud)
- **Хранилище файлов**: S3-совместимое (Timeweb Cloud)
- **Зависимости** (основные):
  - Avalonia
  - CommunityToolkit.Mvvm (или ReactiveUI — если использовал)
  - MySql.EntityFrameworkCore / Pomelo.EntityFrameworkCore.MySql
